# 隐私政策站点(GitHub Pages)

把本目录**里面的所有文件**(含隐藏文件 `.nojekyll`)复制到一个新的**公开** GitHub 仓库根目录:

1. 新建公开仓库,例如 `auracalendar`
2. 全局替换 `YOUR-EMAIL@example.com` 为你的真实邮箱(`index.html`、`privacy.html` 各有出现)
3. 提交并推送
4. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)` → Save
5. 等 1–2 分钟,隐私政策地址为:
   `https://<你的用户名>.github.io/<仓库名>/privacy.html`
6. 把这个地址填到 Partner Center 的隐私政策 URL

> 复制到仓库时不要带上本 README 也可以(它不影响页面)。
